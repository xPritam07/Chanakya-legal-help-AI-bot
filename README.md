# Chanakya Legal Help AI Bot

## Overview
The Chanakya Legal Help AI Bot is an innovative solution designed to assist users with a variety of legal inquiries and issues. Leveraging artificial intelligence, this bot provides accurate information, resources, and guidance tailored to the user's specific legal needs.

## Features
- Provides answers to common legal questions.
- Guides users through legal procedures and documentation.
- Offers resources and links to legal assistance and directories.
- Continuously learns from user interactions to improve accuracy.

## Technologies Used
- **Programming Language:** Python
- **Frameworks:** Flask/Django for the web interface
- **AI Libraries:** TensorFlow/PyTorch

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/xPritam07/Chanakya-legal-help-AI-bot.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Chanakya-legal-help-AI-bot
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the bot:
   ```bash
   python app.py
   ```

## Usage
- After running the bot, access it via the provided URL (usually http://127.0.0.1:5000).
- Follow the prompts to ask your legal questions and get tailored responses.
